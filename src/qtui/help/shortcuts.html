Keyboard shortcuts

These are the keys this window handles. On a Mac, Control in this table is the Control key, not the Command key. Mouse actions on the waterfall are in The waterfall.

ActionKeys
QuitCommand-Q on a Mac, Control-Q on Linux. File, Quit uses the usual Quit shortcut.
TransmitControl-T, with the transmit box focused, and no other modifier key. If you are already transmitting or tuning, this does not start again.
Return to receiveControl-R, with the transmit box focused, and no other modifier key. This also stops a tune tone.
Stop transmit, tune, or a repeating macroEscape, then Escape again within one second. No Shift, Control, Option, or Command. Works anywhere in the main window. The first Escape alone does nothing. The second stops a transmission or a tune tone at once, and cancels a macro that is counting down.
Run a macroF1 through F12, with no other key held. F1 is the left button of the set on screen, F12 the right. Works anywhere in the main window. A key that is held down does not run the macro again.
Open this helpCommand-? on a Mac, or Help, TCIdigi Help. On Linux there is no key for it, because F1 runs the first macro; use the Help menu.

Help, Keyboard shortcuts opens this page. Help, fldigi manual (web) opens the manual in your browser.
