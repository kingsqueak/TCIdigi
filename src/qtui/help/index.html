TCIdigi Help

TCIdigi is fldigi's digital modes in this window. The radio's dial, mode, and filter, and the modem audio, go over TCI, the link used by a ZeusSDR or ExpertSDR3 radio. There is no sound card and no other radio control in this program. Settings are kept in ~/.tcidigi, separate from fldigi's own folder ~/.fldigi. TCIdigi does not read ~/.fldigi.

Open this from the Help menu, TCIdigi Help. The fldigi manual on the web is the reference for how each mode works and for the full list of macro tags. These pages cover this window.
