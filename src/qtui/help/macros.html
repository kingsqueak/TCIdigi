Macros

The row under the transmit box is twelve macro buttons, one set at a time. There are four sets. The number at the right of the row is the set, from 1 to 4. Click that number for the next set. Right-click it for the previous set.

Click a button to run its macro. The tip names the function key that runs it: F1 is the left button, through F12 on the right. The keys work anywhere in the main window, with no other key held. Holding a key down does not run the macro again. Right-click a button to edit it. An empty button says so.

The editor is titled Edit macro. It names the set and the button. The first line is the label on the button. The box under it is the macro text. Save keeps the edit. Close discards it.

The editor fills in these tags when the macro runs: <MYCALL>, <CALL>, <NAME>, <QTH>, <LOC>, <RST>, <MYLOC>, <TX>, and <RX>. <TX> and <RX> are how a macro switches to transmit and back to receive. The text the macro produces is shown in the transmit box. Your own call, name, and location come from Configure, Station. The other station comes from the call, name, QTH, grid, and RST boxes.

The full list of tags is in the fldigi manual. This window does not show that list.

A macro that repeats shows a seconds countdown at the top right of the window, to the left of TxID. Click that number to stop the macro and return to receive. Escape twice does the same. See Keyboard shortcuts.
